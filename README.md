**Что ищу:** junior-позицию в команде, где смогу расти как backend-разработчик,

## 📁 Проекты

### Events Aggregator
Сервис-агрегатор событий на FastAPI. Кэширует события из внешнего API, добавляет 
фильтрацию по дате и пагинацию, регистрацию на мероприятия с выбором места.

**Стек:** Python, FastAPI, SQLAlchemy 2.0 (async), PostgreSQL, Alembic, Docker Compose, 
httpx, pytest, JWT.

[Ссылка на репозиторий](https://github.com/GrigoriyTsedrick/events-aggregator)

### Сервис бронирования столов в кафе
REST API для управления бронированиями столов. JWT-аутентификация, разграничение 
прав (пользователь/менеджер/админ), полный CRUD-цикл бронирований.

**Стек:** Python, FastAPI, SQLAlchemy, PostgreSQL, Alembic, Docker Compose, pytest.

*Учебный проект Яндекс Практикума.*

### Сервис публикации рецептов и списка покупок
Backend для сервиса с рецептами. Регистрация и авторизация по токену, подписки 
на авторов, формирование списка покупок и выгрузка в PDF.

**Стек:** Python, Django, Django REST Framework, PostgreSQL, Docker, Nginx, 
CI/CD (GitHub Actions).

*Учебный проект Яндекс Практикума.*
